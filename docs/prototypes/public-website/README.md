# 循证知问网站交互原型

范围于 2026-09-29 经用户确认：

- 首页与公众版、专业版双入口。
- 示例提问、固定回答、引用详情与本地反馈。
- 专业版 PICO 条件；主题库列表与五个主题详情。
- 方法与来源、隐私和使用说明。
- 加载、证据不足、隐私拦截、服务繁忙状态。
- 电脑与手机布局，沿用青绿色品牌。

## 预览

直接在浏览器打开 `index.html` 即可。所有字体和资源均在本地，不需要安装依赖。

也可从此目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。使用 hash 路由，支持浏览器前进、后退和页面刷新。

## 体验路径

1. 首页 → 公众版 → 点选示例 → 查看回答示例。
2. 点击正文引用 → 查看来源 → 关闭弹窗 → 体验反馈。
3. 切换专业版 → 展开 PICO → 再次提交 → 查看完整证据上下文。
4. 使用“原型工具”切换加载、证据不足、隐私拦截和繁忙页面。
5. 进入主题库 → 打开详情 → 查看引用 → 体验该主题。

## 示例数据与边界

`content.js` 基于项目现有五个知识页与文献快照，保留原有陈述及来源。本次原型制作未重新开展临床评审。缺失元数据如实留空。

原型不调用模型或在线检索、不保存问答、不发送反馈、不使用分析脚本。只有明确的示例问题展示对应固定内容，其余自由输入进入未支持状态，不执行真实医学推理。点击原始文献链接会访问对应外部网站。

本次没有实现账号、收藏、支付、上传、真实后端或服务器部署。产品后端设计见 `docs/superpowers/specs/2026-09-29-public-website-design.md`。

浏览器验收记录见同目录的 `QA.md`。
