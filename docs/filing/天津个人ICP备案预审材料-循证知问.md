**域名注册商与备案接入商是两个角色。** 如最终使用符合条件的阿里云中国内地服务器，可在阿里云办理；如选择腾讯云等其他服务器，应由对应接入商办理。只有域名、尚无符合条件的接入资源时，可以准备材料及咨询，但接入信息尚不具备正式提交条件。[服务器检查说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-server-access-information-check)

## 三、网站内容说明草稿

以下文字可在备案专员确认主体路径后，用于网站情况说明或备注；若字段有字数限制，按要求缩写并保留医学内容与交互问答事实。

> “循证知问”拟提供免费的一般健康与医学研究资料浏览、主题检索和交互式证据问答服务。首版涵盖成人高血压、血脂异常、2 型糖尿病、脑卒中二级预防及饮食与心血管风险。用户提交一般问题或研究条件后，系统从内置知识页和精选文献快照中检索并整理来源摘录，展示引用标识、文献链接、适用范围与局限。当前不调用外部大模型或实时文献检索接口。网站用于知识学习、教学与研究，不提供个体诊断、处方、剂量调整、停药或换药建议；首版无注册、支付、文件上传、论坛和公开评论功能。

### 栏目与交互

| 栏目 | 实际功能 |
|---|---|
| 首页 | 介绍用途、覆盖主题及公众版和专业版入口 |
| 公众版 | 提交一般健康知识问题，阅读带来源引用的摘录整理结果 |
| 专业版 | 补充人群、干预、对照、结局四项研究检索条件；不代表医生身份认证 |
| 主题库 | 浏览五个主题的资料、适用范围、局限和参考来源 |
| 引用详情 | 展示文献题名、年份、标识、必要摘录和原始链接 |
| 方法与来源、隐私、使用说明 | 说明检索方式、数据处理及使用边界；生产托管与日志信息待部署后补全 |

### 当前数据与技术情况

- 前端为 React，后端为 FastAPI；服务端复用项目证据检索、门控和引用校验流程。
- 当前 Web 入口使用五个知识页和十条精选文献快照，未启用私有 PDF、云端证据库、外部大模型或实时文献检索。
- 网站以简体中文呈现，部分文献题名、标识及外部来源页面可能为英文。
- 提交内容经本站接口处理。页面草稿和结果保存在页面内存，刷新或关闭后清除；当前应用不持久化问答历史。
- 生产服务器、代理日志、安全日志及数据保留期限尚未配置，应在上线前如实补充。自动隐私检查存在漏检可能。
- 引用和规则校验属于工程检查，当前未完成独立临床评审。

### 天津需要特别核对的项目

- 主办人须年满 18 周岁；域名持有者需与主办人一致，域名剩余有效期应大于 30 天。[天津备案规则](https://help.aliyun.com/zh/icp-filing/icp-filing-regulations-for-tianjin-1/)
- 天津个人备案的联系手机与应急手机不能相同；号码由本人在官方页面提供。[主办者填写说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/the-fill-in-the-sponsor-information)
- 备案名称与上线实际名称、内容须一致；“循证知问”目前是候选名称，尚未获得审核确认。[网站信息填写要求](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/fill-in-website-information)
- 阿里云天津规则页还列有域名隐私保护处理要求；具体功能名称及是否需操作，请让备案专员结合账号状态确认。[天津备案规则](https://help.aliyun.com/zh/icp-filing/icp-filing-regulations-for-tianjin-1/)
