## 本轮必须完成

### 1. 运行基线与管理员诊断

增加本地诊断命令，记录构建/提交标识、依赖版本、配置白名单、语料计数/哈希、可选索引状态。禁止输出凭据或完整环境变量。无 Git、无 PDF、缺核心资源应准确区分，默认不联网。

整理真实部署方式、启动/重启、持久目录和回滚办法。没有网站地址或服务器访问时，仅收集必要缺失信息并继续其余工作；将线上版本与健康写为未核验。

### 2. Web 请求保护与脱敏记录

统一 Web/Tool 的输入规则：strip 后非空、最多 4000 字符，参数合法；验证失败不调用 pipeline。

Web 当前共享缓存 pipeline，而 Tool 已用锁保护可变后端状态。为共享调用增加有界排队与并发保护，默认锁等待上限 5 秒，异常后必须释放；不要把单进程保护描述成跨进程限流。生成 request_id，确保请求间诊断互不串联。

Web 失败显示固定提示与请求编号，正确处理上次结果，避免旧答案被误当作本次成功。运营记录使用字段白名单和 capture_content=False，只记录版本、状态码、耗时、计数与实际后端。默认不保存题干、查询词、答案正文、PHI、密钥、完整异常或来源响应体；不得直接把离线评测 recorder 接到生产。MCP stdout 保持协议专用。

### 3. 真实的来源状态与故障回退

为实时源、云检索和生成器补结构化状态：未启用、未尝试、成功、有响应但无结果、失败、回退；原因使用稳定代码。保持已有字段兼容，不用解析 trace 推导结果。

当前顶层 degraded 主要覆盖检索/重排；LLM 失败可能静默回退，used_live_api 也不能证明取回证据。修正 UI 和运行记录，使它们准确呈现实际执行。无 LLM key 的正常离线抽取不算故障。

保留既有兜底及全部安全校验。LLM 单次超时可配置，默认保持 45 秒；重试等待有界，建议默认上限 5 秒，测试异常 Retry-After。排队、单次请求与重试上限要分别说明，不能宣称已经提供全链路硬截止。

### 4. 新环境可复现基线、CI 和交付

复用现有隔离 runner。当前工作树缺少 Git 忽略的历史 data/eval_runs，run_p0 即使 C0 也依赖历史冻结语料。先做资产预检；取得历史工件则核对哈希，否则建立带独立身份的当前 C0 基线，不可拿当前数据冒充历史 B0 或旧实验复现。C1 缺索引则明确未执行。

冻结当前代码、内置数据、旧 15 题、配置、依赖和哈希；唯一输出目录、禁止覆盖、显式 Settings、隔离环境、禁止外网，并验证两次语义一致。新增 Settings 字段必须同步 offline_runner 的显式清单。

CI 接入轻量 C0 回归和本轮故障测试，保留 Python 3.11 真实 MCP stdio 必测。完成 Web 成功、拒答、异常恢复的交互验证；在测试环境记录并发 1/4 的延迟与资源情况，说明共享锁的吞吐限制。线上探测与真实问答分开验收。

交付服务器运行手册，包含进程健康、应用就绪、日志轮转、备份、版本核验和代码/配置/语料一起回滚。根据实际部署补内容，不凭空加入 Docker、Kubernetes 或新数据库。

## 保持的约束

- 默认仍为 source_preserving 候选池、legacy Top-8、legacy 检索、deterministic 重排。
- Top-8/Top-5、最少独立来源 3、0.18/0.5 安全阈值不变。不得为了通过测试放松拒答或引用门禁。
- PHI 前置零外部调用、输出净化和后置拒答必须保留；请求中不下载模型、不建索引。
- 保留旧 15 题、旧评分器、历史工件及原索引；不对题号或 PMID 做特判。
- 本轮不切换新检索后端、不替换生产语料、不扩账户/聊天历史等功能。后续 48 题独立试点与语料治理只列交接项；不得伪造临床金标准或人工评审结论。
- 完成本地可逆工作无需反复询问。生产变更和付费外部调用依据明确授权进行；本 prompt 授权本地实现与验证，生产发布另行确认。

## 工作方法与验收

逐任务先补能暴露缺口的测试，再最小实现，运行相关测试。独立模块可并行，接口与文件所有权明确；有共享状态的改动顺序完成。测试使用合成输入与 mock，不发真实患者信息。

重点验证：4000/4001 字符、两个并发请求诊断归属、排队超时、异常后恢复、日志无敏感内容、单源/全源失败、LLM 坏 JSON/429/超时、正常离线不报故障、缺历史工件与可选索引、PHI 零外发和 MCP stdout。

最终运行完整适用测试、离线 smoke、桌面资源检查和 C0 回归；做一次独立代码审查并修复本轮相关问题。测试缺依赖、环境阻碍、线上未核验均如实记录，skipped 不当成通过。
