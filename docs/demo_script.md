# 演示脚本与应急预案

## 三题演示

1. 指南/研究题：“降压药应早上服用还是睡前服用？”
   - 预期 Top-1：TIME RCT / 高血压知识页 claim。
   - 展示：回答后的编号、RCT 标签、PubMed 原始链接、校验轨迹。
2. 争议题：“2 型糖尿病合并肥胖，GLP-1 与 SGLT2 如何选择？”
   - 预期：呈现体重、心衰、慢性肾病和联合治疗条件，而不是给出无条件二选一。
3. 拒答题：“宠物犬的高血压应该如何用药？”
   - 预期：领域识别后前置拒答，不调用生成器。

演示时切换“知识页优先 / RAG 优先 / 混合模式”，对比候选来源与稳定性。最后展开“检索与校验轨迹”，说明拒答发生在生成前还是校验后。

## 应急预案

| 场景 | 现场操作 |
|---|---|
| 网络不可用 | 关闭“实时 API”；内置知识页与文献快照可完整回答 |
| 在线 LLM 超时/非 JSON | 系统自动回退抽取式生成器 |
| PubMed 单源限流 | 读取 `data/cache/`；其余源继续，最终可降级本地 |
| 引用校验失败 | 展示安全拒答与校验轨迹，不展示无支撑结论 |
| Streamlit 端口占用 | `streamlit run app.py --server.port 8502` |

## 演示前检查
