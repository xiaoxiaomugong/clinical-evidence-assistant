# 离线工程评估报告

![固定测试集指标](assets/evaluation_metrics.svg)

本报告对应语料版本 `v3`、混合模式、关闭实时 API 的固定回归测试。评估环境接入了基于 PyMuPDF 多栏重排的 500 条 PMID PDF 本地数据源（18,002 个全文/摘要 chunk）；该本地语料和生成索引不随仓库分发。测试集包含 15 题，其中 12 题应回答、3 题应拒答。

| 指标 | 结果 |
|---|---:|
| Recall@8 | 75.0% |
| MRR | 95.8% |
| nDCG@8 | 75.5% |
| 引用准确率 | 100.0% |
| 受支持陈述率 | 100.0% |
| 关键点覆盖率 | 80.0% |
| 拒答正确率 | 100.0% |
| 平均端到端延迟 | 41.1 ms |

这些数字是针对固定问题集的工程回归指标，证明检索映射、输出净化和拒答链路按预期工作；它们不构成临床有效性验证，也不能外推到真实世界的全部问题。当前 12 条可回答题已加入人工指定的文献/知识页 `relevant_source_ids`；Recall@8 按检出的唯一相关来源数计算，nDCG 的理想排序包含全部已标相关来源，不再把“命中任意同主题条目”计为 100%。qrels 仍是稀疏小样本，因此这些指标不应用于宣称系统优于其他产品。

本次评估启用了文献级 qrels 与原子陈述净化：Recall@8 从旧口径的 100% 校正为 75.0%，不支持的陈述和引用在计分及 UI 展示前删除，关键点覆盖率从旧基线的 89.6% 降至 80.0%。这些变化被如实保留，不通过宽松相关性或引用规则换取更高分。

复现命令：

```bash
python3 eval/run_eval.py --mode hybrid
python3 eval/run_compare.py
```

回归脚本输出 JSON、CSV 与 SVG。比较脚本锁定模型、温度、语料版本和回答 schema，并保存 Arm A 纯 LLM、Arm B 正常 RAG、Arm C 劣化 RAG 的全部原始工件；纯 LLM 对照需要配置 `LLM_API_KEY`，未配置时明确记录为 skipped。
